## Overview

EkoX Sentinel provides a structured way to automate DeFi protocol workflows on the Hoodi network. It is designed for recurring claim and yield activities, while its monitoring capabilities help track changing protocol conditions without requiring constant manual checks.

The tool combines scheduling, monitoring, alerts, reporting, and multi-strategy execution for protocol-driven and airdrop-style tasks. Gas-aware transaction handling is also included to help users make more considered decisions about when operations should run.
